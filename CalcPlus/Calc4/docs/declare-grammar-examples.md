# Calc4 Declare Grammar Examples

이 문서는 Calc4 선언문 문법 한 줄을 예시 중심으로 풀어쓴 메모다.

대상 문법은 [`CalcPlus.g4`](/home/jhlim/other/cs/compiler/study/rancho/CalcPlus/Calc4/CalcPlus.g4)의 아래 부분이다.

```antlrv4
'int' VAR (',' VAR)* ';'            # Declare
```

## 한 줄 해석

의미는 아래와 같다.

- `int` 키워드가 먼저 온다.
- 변수 이름 `VAR`가 최소 1개는 반드시 있어야 한다.
- 그 뒤에는 `, 변수이름`이 0번 이상 반복될 수 있다.
- 마지막은 항상 `;`로 끝나야 한다.

즉 선언문은 이런 꼴이다.

```text
int 변수;
int 변수, 변수;
int 변수, 변수, 변수;
```

## 토큰 단위로 읽기

예를 들어 아래 문장을 보자.

```c
int a, b, c;
```

문법 조각에 대응시키면 이렇게 읽는다.

- `'int'` -> `int`
- 첫 `VAR` -> `a`
- `( ',' VAR )*` -> `, b`, `, c`
- `';'` -> `;`

즉 이 선언문 하나는 의미적으로는 아래와 비슷하다.

```text
declare("a")
declare("b")
declare("c")
```

## 정상 예시

### 예시 1. 가장 단순한 선언

```c
int a;
```

가능하다.

- 변수는 1개여도 된다.
- 선언 직후 `a`의 초기값은 `0`이어야 한다.

### 예시 2. 여러 변수 선언

```c
int a, b;
```

가능하다.

- 한 문장에서 여러 변수를 선언할 수 있다.
- 내부적으로는 `a`, `b`를 순서대로 각각 등록하면 된다.

### 예시 3. 여러 개를 더 늘린 선언

```c
int a, b, c, d;
```

가능하다.

- `( ',' VAR )*`의 `*`는 0번 이상 반복이라는 뜻이다.
- 따라서 쉼표 뒤에 변수 이름이 계속 붙는 형태를 허용한다.

### 예시 4. 블록 안 선언

```c
{
  int a;
}
```

가능하다.

- 선언문 `Declare`는 `stmt`다.
- 블록 안에는 `stmt`가 올 수 있으므로 선언도 블록 안에 들어갈 수 있다.

### 예시 5. 바깥과 같은 이름의 내부 선언

```c
int a;
{
  int a;
}
```

가능하다.

- 이건 같은 이름의 재선언이지만, 스코프가 다르므로 허용된다.
- 내부 `a`는 바깥 `a`를 가린다.

## 실패 예시

### 예시 6. 변수 이름이 없음

```c
int ;
```

불가능하다.

- 첫 `VAR`가 필수인데 빠져 있다.

### 예시 7. 쉼표 뒤 변수 이름이 없음

```c
int a, ;
```

불가능하다.

- `( ',' VAR )*`는 쉼표가 나오면 그 뒤에 반드시 `VAR`가 와야 한다.

### 예시 8. 끝의 세미콜론이 없음

```c
int a
```

불가능하다.

- 선언문은 반드시 `;`로 끝나야 한다.

### 예시 9. `int` 키워드가 없음

```c
a;
```

불가능하다.

- 선언문은 무조건 `int`로 시작해야 한다.

### 예시 10. 식을 섞어서 선언하려고 함

```c
int a = 1;
```

Calc4 문법에서는 불가능하다.

- 현재 문법의 선언문은 이름 나열만 허용한다.
- 선언과 초기화가 합쳐진 문법은 없다.

### 예시 11. 괄호나 다른 기호를 변수 목록에 넣음

```c
int (a);
```

불가능하다.

- 선언문은 `VAR`만 받는다.
- 괄호는 선언 규칙에 포함되어 있지 않다.

### 예시 12. 숫자로 시작하는 이름

```c
int 1a;
```

불가능하다.

- [`CalcPlus.g4`](/home/jhlim/other/cs/compiler/study/rancho/CalcPlus/Calc4/CalcPlus.g4)에서 `VAR`는 `[A-Za-z]+`다.
- 즉 현재 문법상 변수 이름은 영문자만 가능하다.

### 예시 13. 숫자가 섞인 이름

```c
int a1;
```

이것도 불가능하다.

- 현재 `VAR` 규칙은 숫자를 허용하지 않는다.
- 따라서 `a1` 같은 이름은 Calc4 문법에서 변수명이 아니다.

## 문법은 맞지만 시맨틱에서 실패하는 예시

아래는 "파싱은 되지만 실행 단계에서 오류"인 경우다.

### 예시 14. 같은 스코프 재선언

```c
int a;
int a;
```

문법상으로는 둘 다 각각 올바른 선언문이다.

하지만 시맨틱 규칙상은 실패해야 한다.

- 같은 스코프에서는 같은 이름을 다시 선언할 수 없다.
- 이 오류는 보통 `SymbolTable.declare("a")`에서 잡는다.

### 예시 15. 한 문장 안에서 같은 이름 중복

```c
int a, a;
```

이것도 문법상으로는 파싱될 수 있다.

하지만 시맨틱 규칙상 실패해야 한다.

- 첫 번째 `a` 선언 후
- 같은 스코프에서 두 번째 `a`를 또 선언하려 하기 때문이다.

### 예시 16. 블록 밖에서 내부 변수 사용

```c
{
  int a;
}
write(a);
```

선언문 자체는 정상이다.

하지만 실행 시점에는 실패해야 한다.

- 블록이 끝나면 내부 스코프가 사라진다.
- 따라서 마지막 `a`는 정의되지 않은 변수다.

## Visitor에서는 어떻게 보이는가

이 선언문은 visitor에서 `visitDeclare(ctx)`로 들어온다.

예를 들어:

```c
int a, b, c;
```

이라면 보통 `ctx.VAR()`에서 `a`, `b`, `c` 토큰 목록을 얻을 수 있다.

구현 의도는 대략 아래와 같다.

```python
def visitDeclare(self, ctx):
    for token in ctx.VAR():
        name = token.getText()
        self.symbols.declare(name)
```

즉 visitor는 선언문 전체를 한 번 받고, 그 안의 모든 변수 이름을 꺼내 심볼 테이블에 하나씩 등록한다.

## 이해 체크용 짧은 질문

아래가 보이면 이해한 것이다.

- `int a;` 는 가능하다.
- `int a, b, c;` 도 가능하다.
- `int ;` 는 안 된다.
- `int a = 1;` 는 현재 Calc4 선언문에서는 안 된다.
- `int a, a;` 는 문법상 읽힐 수 있어도 시맨틱상 오류다.
- `int a; { int a; }` 는 스코프가 다르므로 허용된다.
