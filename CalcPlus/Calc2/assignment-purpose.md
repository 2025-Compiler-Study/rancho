# CalcPlus 과제 목적 정리

## 1) 과제의 큰 목적 (subject.md 기준)
이 과제의 핵심 목적은 **ANTLR4를 사용해 작은 계산기 언어를 단계적으로 확장하면서, 파서 전단(front-end) 해석과 시맨틱 처리(의미 해석)를 익히는 것**입니다.

- Calc-0: 수식 파싱/계산(사칙연산, 괄호, 우선순위)
- Calc-1: 변수 할당/참조, 미정의 변수 기본값(0) 처리
- Calc-2: 조건 분기(`if/else`) 실행
- Calc-3: `read`/`write` 입출력까지 연결

즉, 단순 문법 작성이 아니라, Visitor/Listener로 실제 실행 가능한 인터프리터 동작을 만드는 연습이 목적입니다.

## 2) 이 디렉토리(Calc2)에서의 직접 목적
현재 `Calc2` 폴더 맥락에서는 **Calc-2 단계 구현**이 중심입니다.

- 문장 단위 실행: `stmt+`
- 변수 할당문 실행: `VAR = expr;`
- 조건문 실행: `if (cond) { ... } else { ... }` (`else` 생략 가능)
- 비교 연산 지원: `==`, `!=`, `<`, `>`, `<=`, `>=`
- 블록 스코프는 도입하지 않고(전역 메모리), 프로그램 종료 시 변수 최종 상태를 확인
- 미정의 변수는 `0`으로 간주

## 3) 문법(.g4)로 본 학습 포인트
`CalcPlus.g4`는 다음 역량을 확인하도록 구성되어 있습니다.

- 재귀 `expr` 규칙으로 연산자 우선순위 처리
- `stmt`, `cond`, `block` 규칙 분리로 제어문 문법 구조화
- 라벨(`ExprAssign`, `IfElse`, `MulDiv` 등) 기반으로 Visitor 메서드 매핑

결론적으로 이 과제는 **"문법을 파싱 가능한 형태로 설계" + "파스트리를 실제 실행 의미로 연결"**하는 전체 흐름을 연습하는 과제입니다.

## 4) 참고 메모 (현재 저장소 상태)
- `test_calc2.py`, `calc2_visitor.py`는 `calc2` 시작 규칙 기반 평가를 전제로 작성되어 있습니다.
- 현재 `CalcPlus.g4`는 시작 규칙 이름이 `program`으로 보이므로, 문법 재생성 시 시작 규칙 정합성(`program` vs `calc2`)을 맞추는 점을 확인하는 것이 좋습니다.
